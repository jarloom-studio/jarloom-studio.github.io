# Jarloom Studio

Five-page static service website, plus a public business status dashboard.

The portfolio contains six fictional product concepts, not client work. The logo was generated in Canva. Product visuals were created with built-in image generation; no additional API purchase was made.

Enquiry forms prepare an email addressed only to y3m12005@gmail.com and require the visitor to send it. No backend, customer account, recurring billing or payment collection is implied. Checkout remains inactive until verified.

Design credits describe the trial/monthly design allowance, not a stored cash balance. Status counts are verified snapshots in status.json; the dashboard checks that file each minute while open and does not automatically read sales or inbox activity. Update verifiedAt with every verified business update.

Open index.html for a local preview; use a static server for the JSON dashboard. GitHub Pages serves the published copy. Source retains ; the GitHub upload bundle flattens assets to match browser uploads.
