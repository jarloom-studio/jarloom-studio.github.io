# Jarloom Studio

Five-page static service website, plus a public business status dashboard.

The portfolio contains six fictional product scene studies and five typography-led ad concepts, not client work. New ad concepts vary camera angle, framing and colour, with fictional brand names and baked-in headlines, supporting copy and calls to action. The website includes animated headings, a rotating product showcase, depth effects, a swipeable campaign preview, scroll progress and motion pause controls. The logo was generated in Canva. Product visuals were created with built-in image generation; no additional API purchase was made.

Product briefs and adjustments use embedded Tally forms (kdD0M6 / XxVRZO), with owner notifications enabled. Client uploads and responses are held in Tally. They are enquiries, not automatically accepted orders or instant image generation. Checkout remains inactive until verified.

Design credits describe the trial/monthly design allowance, not a stored cash balance. Status counts are verified snapshots in status.json; the dashboard checks that file each minute while open and does not automatically read sales or inbox activity. Update verifiedAt with every verified business update.

Open index.html for a local preview; use a static server for the JSON dashboard. GitHub Pages serves the published copy. Source retains ; the GitHub upload bundle flattens assets to match browser uploads.
